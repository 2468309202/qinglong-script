## 📋 Script Description

This repository contains automated scripts used in my daily routine, primarily covering the following functions:
* **Life/Logistics**: SF Express, including check-ins, lucky draws, and Lunar New Year tasks.
* **Cloud Services/Disk**: Tianyi Cloud Disk check-in, Tianyi Zhiling, 189 Email, and Microsoft Rewards.
* **Entertainment/Social**: Bilibili check-in, EPIC free game claiming, and Kuaishou Lite tasks.
* **Utilities/Mini-Programs**: Tianji mini-program, Jiangxin Zhonghua, JLC (JLCPCB), and airport auto-renewal modified version.
